# Reset Run

Acompaña a **Resetbot** en una carrera por un centro de datos. Salta los obstáculos, conserva tus vidas y llega lo más lejos posible para superar tu récord.

## Cómo jugar

1. En la pantalla de inicio, pulsa **Espacio**, **↑** o haz **clic izquierdo** para comenzar.
2. Resetbot corre automáticamente. Salta cuando se acerque un obstáculo.
3. Espera a tocar el suelo antes de volver a saltar.
4. Mantén el ritmo: la velocidad aumenta a medida que avanzas.

## Controles

| Acción | Control |
| --- | --- |
| Comenzar la carrera | Espacio, ↑ o clic izquierdo |
| Saltar | Espacio, ↑ o clic izquierdo |
| Volver a la pantalla inicial | R |
| Volver al inicio tras Game Over | Espacio, ↑ o clic izquierdo |

También puedes tocar la pantalla para comenzar, saltar o volver al inicio tras Game Over.

## Vidas y obstáculos

Empiezas cada carrera con **tres vidas**. Cada choque con un obstáculo te quita una vida y te concede un breve periodo de protección frente a nuevos golpes. Al perder las tres vidas, termina la partida.

## Distancia y récord

Tu puntuación es la **distancia recorrida en metros**. Durante la carrera puedes consultar la distancia, el récord, las vidas restantes y la velocidad.

Al terminar una partida, tu mejor marca se guarda automáticamente en el dispositivo para que puedas intentar superarla la próxima vez.

## Otra oportunidad

Cuando termine la animación de **Game Over**, pulsa Espacio, ↑ o haz clic para volver a la pantalla inicial. Pulsa de nuevo para comenzar otra carrera con tres vidas y la velocidad inicial.

**¡Calcula cada salto y supera tu mejor marca!**

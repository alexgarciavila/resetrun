# Reset Run

**[Juga a Reset Run](https://alexgarciavila.github.io/resetrun/)**

Resetbot corre automàticament per carrers, tallers i centres de dades. Esquiva els obstacles i arriba tan lluny com puguis. La velocitat augmenta a mesura que avances. Tens **tres vides** i cada xoc te'n resta una.

## Com es juga

Prem **JUGAR** al menú per començar. Les indicacions dels obstacles et diuen si cal saltar, fer un doble salt o lliscar.

| Acció | Ordinador | Mòbil |
| --- | --- | --- |
| Saltar | Espai, ↑ o clic esquerre | Toca **↑ SALTA** |
| Fer un doble salt | Torna a prémer mentre ets a l'aire | Torna a tocar **↑ SALTA** mentre ets a l'aire |
| Lliscar | Mantén ↓, Ctrl o el clic dret | Mantén **↓ LLISCA** |
| Tornar al menú al final de la partida | Espai, ↑ o clic esquerre | Toca fora del rànquing |

## Modes i rècords

A **MONS** pots triar l'escenari i el mode. Amb **MÓN FIX** corres al mateix escenari. Amb **SENSE FI** canvies de món cada 1.000 metres i, en acabar, pots enviar la teva distància amb un àlies. Consulta les deu millors marques a **RÈCORDS**.
